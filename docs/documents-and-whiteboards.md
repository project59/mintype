# Documents and whiteboards

Every page in Mintype is either a **document** or a **whiteboard**. Create either one from the **+** next to **Notes** in the sidebar, or from a workspace's home page.

## Documents

Documents are continuous rich-text pages. Mintype saves them as [Markdown](https://commonmark.org/help/), so your writing stays portable and exports cleanly.

### Formatting

The toolbar at the bottom of the page has fonts, text sizes, headings, bold, italic, underline, strikethrough, inline code, lists, text colour, highlights, links, superscript and subscript. Common Markdown shortcuts also work as you type, such as `#` for a heading, `-` for a list and `**bold**`.

### Blocks

Type `/` on an empty line, or press **+** in the toolbar, to insert a block:

| Block | What it does |
| --- | --- |
| Callout | A highlighted box for notes, warnings, errors and successes. Pick the type inside the block. |
| Code block | Code with syntax highlighting. Pick the language inside the block. |
| Table | A simple table. Use the grips and **+** bars to add, move and remove rows and columns. |
| Columns | Two to four columns side by side, with layout presets. |
| Section | A collapsible box with a title and an optional colour. |
| Page link | A link to another page in your workspace. You can also type `@`. |
| YouTube video | An embedded video. |
| Maps | An embedded Google Maps view. |
| To-do list | Checkboxes. Press Enter for a new item and Tab to nest one. |

You can also paste images. They are compressed and stored inside the page, so they are encrypted along with your text.

### Moving blocks

Hover over a block to show its handle on the left. Drag the handle to move the block, or click it (tap it on a phone) for a menu to move the block up or down, duplicate it, or delete it.

## Whiteboards

Whiteboards are an infinite canvas built on [tldraw](https://tldraw.dev). They include sticky notes, shapes, freehand drawing, arrows, text, groups and images.

### Markdown boxes

The Markdown box tool puts the document editor onto the canvas. Double-click a box to edit it, and you can use the same formatting and blocks as in a document. While you are not editing it, the box shows a static preview.

### Images

Images added to a whiteboard are stored inside the whiteboard and encrypted with it. Each image can be up to 5 MB.

### Undo and history

Use the undo and redo buttons at the top of the page, or Ctrl+Z / Cmd+Z. Whiteboard history and document history are kept separately.

## Search

The search button at the top right searches page titles, document text, and text on whiteboards. Sensitive pages are not included. [What is stored where](data-storage.md#the-search-index) explains how search works with encrypted notes.

## Other tools

- **Pomodoro timer:** the timer button at the top of a page starts a focus timer.
- **Page export:** a page's options menu can export it as Markdown or JSON. See [Import, export and backups](import-export.md).
